## Regras de composição

- Reaproveite componentes antes de desenhar qualquer coisa. Se falta um detalhe, amplie o componente (nova variante ou propriedade) em vez de criar outro parecido.
- Telas: frame com auto layout vertical, largura ligada a `layout/viewport`, margem `layout/margin` e o mode Responsive do breakpoint aplicado ao frame.
- Seções separadas por `spacing/32`–`48` no mobile e `48`–`64` no desktop.
- Drawers e modais: `overlay/scrim` por trás, `elevation/3`, raio `radius/modal` (no bottom sheet, só nos cantos de cima).
- Componentes com interação de navegação (Header, menu, drawers) ficam na página de layout, não na página Componentes.

## Mapa rápido: wireframe → componente

| No wireframe | Use |
| --- | --- |
| Tag com “%” ou “OFF” | Commerce/Tag Type=Discount |
| Tag “Novo” ou “Lançamento” | Commerce/Tag Type=New |
| Campanha (“Frete grátis”) | Commerce/Tag Type=Promo |
| “Esgotado” | Tag Type=Dark + card State=Unavailable |
| “De R$ X por R$ Y” | Price Block com Show old price |
| “ou 3x de R$…” | Price Block, linha Installments |
| Botão largo no card | Product Card CTA=Full |
| Ícone de carrinho ao lado do preço | Product Card CTA=Compact |
| “− 1 +” | Quantity Selector |
| Item do minicart | Product Card Horizontal Context=Minicart |
| Abas “A / B” | Navigation/Segmented Control |
